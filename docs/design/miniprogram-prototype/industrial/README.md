# 工业杂志风格原型（2026-11-07）

只看样子用的静态原型，不是小程序源码。每个方向一个目录，在浏览器里打开它的 `index.html` 即可；地址后面加 `?full=1`，每台手机会展开成整页长度。

每个原型都是四屏：精选、日报、条目详情、锐奇。数据相同，都是真实数据。

| 目录 | 方向 | 唯一的记忆点 |
|---|---|---|
| `monthly/` | 栏目色标 · 行业月刊 | 书口色标：分类色升级成栏目色，卡片右缘一条色标，日报分节用栏目色块开头 |
| `duotone/` | 双色套印 · 技术期刊 | 竖排刊头：新闻纸 + 钴蓝专色，钴蓝反白竖排“锐奇微报”，配图做成钴蓝单色 |
| `cabinet/` | 机柜灰 · 设备期刊 | 铭牌 + 指示灯：机柜灰底上的白面板，炭灰铭牌标面板名，信号黄小灯标当前位置 |
| `swiss-in-source/`（源码工作树里，未提交） | 国际主义技术期刊 | 上一轮已经写进源码的版本：纸白、墨线三级线制、信号红编号。这里放的是微信模拟器截图 |

公共文件：

- `data.js`：真实数据快照，2026-11-07 06:35 从线上 `/api/mp/v1` 取，时间已换成北京时间。原型里的“现在”是 11 月 7 日 06:40。
- `assets/`：从 `apps/miniprogram/src/assets/` 复制来的 logo 和锐奇官网产品图（来源见小程序 README）。
- `shell.css`、`shell.js`：手机外壳，包括 iOS 状态栏、微信原生导航栏和胶囊。
- `shoot.sh`：用 headless Chrome 截图，生成 `<目录>/shot.jpg` 和 `shot-full.jpg`。


每个方向目录里的 `notes.md` 写了色板、字号、落到 Taro 要改什么，以及风险。

## 怎么比较

`compare-feed.jpg` 把五版精选页放在一起，从左到右依次是：10-29 现行版（改版前）、国际主义技术期刊（已写进源码）、栏目色标、双色套印、机柜灰。前两张是 11 月 6 日晚上的微信模拟器截图，当时的焦点是另一条新闻；后三张是原型，用的是 11 月 7 日的数据。所以几版的内容不同，但版式可以直接对比。
