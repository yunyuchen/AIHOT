# 锐奇热点 小程序原型

- `a/`：客户 2026-10-17 确认的 A 版，八屏，`a/index.html` 并排看，画面之间可以点着走。这是开发的视觉基准。
- `explore/`：精选页的三版“时间轴卡片”探索，`explore/index.html` 并排看。方案一被选中并发展成 `a/`；方案二、三保留作参考。
- 根目录的 `*.dc.html` 和 `canvas.json`：最早一版（白卡片、米白底）的画布源文件，已被否，只留档。

A 版的要点：深色仪表盘头部（墨 #13191c）加浅灰工作区（#f2f3f5）和白卡片；时间轴卡片；节点、计数、分类色标一律圆形，不用方形；星青 #2ce2e8 只做图形、线条、底色和深底上的大数字；tabBar 像微信原生；所有模型写的内容带“AI 摘要”标。
