# 小程序阅读界面改版

采用 design-taste-frontend 的应用界面方向 `framed-sheet`，seed 为 `165996870`。保留 Taro、系统中文字体、原有标识与五个原生 tab。

## 设计依据

这套小程序的实际内容包括：制造精选、同一事件的多家报道、按日期出版的日报、运动健康分类、AI 摘要标识、来源链接、本机收藏、锐奇四类测量产品、公司介绍和公开联系方式。读者先判断消息值不值得看，再读摘要、核对来源或收藏；公司页先回答能提供什么设备，再提供联系入口。

因此把多家报道集中到同一个阅读单元，保留日期和来源数量，减少用于装饰的时间轴与扫描条。页面采用浅灰框架、白色阅读面和深青色操作提示。没有新增宣传数字、客户案例或图片。

## 页面变化

- 精选与运动健康：紧凑刊头、完整宽度的信息流，时段与日期仍分组。列表标题从 16px 调到 18px，摘要从 13px 调到 15px。
- 焦点卡：标题 22px，摘要最多三行，保留来源数和最近时间。
- 日报：日期导航、头条、分类分节，取消卡片与深色头部重叠。
- 条目与事件：采用连续阅读面，标题 24px，摘要 17px / 29px 行高。分享、收藏、来源入口保留。
- 收藏：统一的文章目录样式，保留本机保存的说明。
- 锐奇：产品目录前置，取代两列图标卡；首页新增“联系我们”，滚动到已有联系方式，不自动拨号。
- 错误与空态：按钮高度统一到至少 44px。
