# 一个小程序装制造和运动健康两个板块，明知微信的类目规则

2026-10-17。微信类目“资讯 > 信息资讯”不需要资质，但只适用于“单一行业资讯展示”，备注写明“如提供两个及以上行业资讯相关服务，需选择【文娱-资讯广场】类目”，资讯广场要《互联网新闻信息服务许可证》；按《互联网新闻信息服务许可管理实施细则》第五条，申请方须是境内依法设立的法人，主要负责人和总编辑是中国公民，并配有专职的新闻编辑、内容审核和技术保障人员（类目页 2026-10-16 逐字核对，细则见 cac.gov.cn 2017-05-22）。制造加运动健康按字面就是两个行业。客户（锐奇）仍决定只做一个小程序“锐奇热点”，运动健康是底部的一个 tab，不拆成两个小程序，也不等支付宝。我们按这个做，并把风险写在这里：按“信息资讯”申报，可能被拒，上线后也可能被要求限期整改，整改不了会封禁直至下架，制造板块会一起受影响。

## Considered Options

- 每个板块一个微信小程序，同主体同代码两个构建，各选“信息资讯”：合规，多一次备案和审核。客户否决。
- 微信版不带运动健康 tab，只在支付宝版带：合规，但 V1 是微信，客户要在微信里看到。否决。

## Consequences

- 运动健康 tab 的内容要有服务端开关：被要求整改时，不发版就能把它换成占位内容。
- 申报和页面文案都把站点说成“制造业企业资讯”，运动健康是配套内容，不自称“资讯平台”。
- 运营规范 5.19 禁止按人群展示不同内容、3.1 禁止隐藏类目，所以开关只用于整改，不用于审核时藏起来。
- 一次提审：制造和运动健康一起上，不先发只有制造的版本。所以运动健康行业实例（信源、标准、门槛校准）在 V1 的关键路径上，被拒时整个小程序一起改。客户知悉并选择这样做。
