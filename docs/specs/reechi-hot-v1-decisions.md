# 锐奇微报 V1：已定的事

2026-10-17 用 grill-with-docs 问完、原型确认后的共识。术语按 `GLOSSARY.md`，架构决定见 `docs/adr/`。

## 角色

- 客户：锐奇（做锂电、半导体、薄膜产线的测厚、X 射线、视觉检测设备）。产品拍板的是锐奇老板。
- 开发：本仓库的使用者，承接方。
- 读者：锐奇的客户和同行，制造业的工程师、管理者、工厂员工。匿名，没有账号。

## 产品

- 微信小程序，名字 **锐奇微报**（名字是否可注册待客户用自己的账号查）。公司主体注册。
- 两个板块，一个小程序：**制造**（现有的锐奇制造日报行业实例）和 **运动健康**（新的行业实例，健康和运动合并）。
- 底部五个 tab：精选、日报、运动健康、收藏、锐奇。条目页、事件页是从精选和日报点进去的下钻页。
- 制造板块的栏目：精选流、事件页、日报（最新一期，可按日期翻，分节列表渲染）。
- 运动健康是轻量板块：只有精选流和事件页，没有日报、没有热点榜。内容只做“健康生活”，不做“医疗健康”。信源与取舍标准草案在 `docs/drafts/sports-health-sources-and-criteria.md`，等老板逐条确认。
- 锐奇 tab：公司介绍、产品与案例、联系方式、关于锐奇微报、用户协议、隐私说明、反馈与侵权投诉，以及 AI 生成和不收集个人信息的声明。内容是一页静态 markdown，改内容走发版。
- 不登录，不收集个人信息，收藏和已读只存本机。唯一例外（2026-10-17 定）：读者点“提醒我明天的日报”时，服务端只为这一次待发送的提醒保存 openid、日期和模板，消息发出或过期即删；隐私指引和隐私说明里如实声明。
- 看原文：条目页显示来源名和发布时间，提供“复制来源链接”；来源明确允许全文的（信源配置 `site_fulltext`）站内显示全文；小程序内不打开任何外部网页（业务域名必须备案且自己可控，信源网站做不到）。
- 分享：单条精选和一期日报可分享给好友和群，卡片图用现有分享图服务；事件页不单独分享；不做朋友圈。
- 每日推送降级为日报页的“提醒我明天的日报”按钮：一次性订阅消息，用户每点一次收一条，第二天日报出刊后（08:00 起）发送（发送需要 openid，处理方式见上一条）。主入口是群转发和公众号菜单。
- AI 标识：所有模型写的标题、摘要、日报在小程序里带显著的“AI 摘要”标识，用户协议写明（《人工智能生成合成内容标识办法》2025-09-01 施行）。
- 不做：全部动态、周报月报、主题目录、搜索、排行榜、朋友圈、自定义 tabBar、后台编辑、用户系统。数据统计用微信自带。

## 平台规则（2026-10-16 在微信官方页逐字核对）

- 类目“资讯 > 信息资讯”不需要资质，适用于“单一行业资讯展示”；“两个及以上行业资讯”须选“文娱 > 资讯广场”，要《互联网新闻信息服务许可证》。制造加运动健康按字面是两个行业。**客户明知此规则，仍决定一个小程序装两个板块，一次提审**（ADR 0002）。保险：运动健康 tab 的内容有服务端开关，被要求整改时不发版就能换成占位；申报和文案说成“制造业企业资讯”；开关只用于整改，不用于审核时隐藏（运营规范 5.19、3.1 禁止）。
- 个人主体没有资讯类目，所以是公司主体。
- request 合法域名必须 HTTPS 且 ICP 备案，香港服务器不能用于备案；另有工信部要求的小程序备案（公司主体，1 到 20 个工作日）。
- web-view 业务域名必须备案并在根目录放校验文件，个人主体不开放。
- 订阅消息“仅在点击行为时调用”，一次性模板每次授权一条；长期订阅只对少数类目开放。
- 支付宝“文娱 > 资讯”没有单一行业限制，健康归“医疗健康 > 健康资讯”且专业医疗信息要医疗机构或专业媒体主体。V1 不上支付宝，架构不堵死它。

## 技术与部署

- 小程序用 Taro 4.x，React + TypeScript，原生 tabBar，微信先上，支付宝以后再编译加修补。
- 小程序读新的公开出口 `/api/mp`：和 RSS、MCP 一样从读取层（publication）读，契约独立带版本，响应里给绝对图片地址和 AI 标识字段。`/api/v1` 不为小程序改契约。
- 每个行业实例独立部署，各有自己的数据库、worker、api（ADR 0001）。V1 上线时两套实例同时在跑，小程序知道两个 api 地址，两个域名都进请求白名单、都备案。
- 整套搬到大陆：数据库、api、worker 都在大陆机器。模型是 DeepSeek 官方。2026-10-18 改：大陆机不跑跨境代理、不访问在大陆被屏蔽的站点（早先在大陆机上起分流代理导致云厂商停机），只采大陆能直接访问的信源，被屏蔽的境外源在大陆实例上停用；香港机搬迁后不承担转发。
- 运动健康实例在 V1 关键路径上：信源、提示词、门槛校准要在提审前就绪。门槛用标注样本校准，默认由开发标注。
- 网页 hot.reechi.work 继续运营，是并列的公开出口。后台运营仍在网页 `/admin`。
