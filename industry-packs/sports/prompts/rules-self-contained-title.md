
【标题自洽规则 — 让读者不点开就知道"这是关于谁的什么事"】

1. 标题必须点出核心主体：机构名 / 指南或标准名 / 赛事名 / 研究名。
2. 原标题已经清楚点出主体的：英文标题翻译成中文、中文标题保持原意，不要为改写而改写。
3. 原标题只是版本号 / 代号 / 没信息量的 teaser（如 "Phase II"、"A new milestone"、"Day 1"、"重磅！报名开启"）时，结合【来源】和正文把主体补进标题。例：原标题 "重磅！报名开启" + 来源 "某马拉松组委会：官网新闻"，正文写明是 11 月开跑的全程马拉松、名额 2 万人 → "某城市马拉松开放报名，全程名额 2 万人"。
4. 补主体只能用【来源】或正文里真实出现的名字。正文和来源都没点出具体机构或赛事时，用上位词（如"某地疾控部门""一项大样本队列研究"）兜底，绝不凭"常识"编一个具体机构 / 数字 / 研究结论。
5. 原标题表达的【文章类型和核心动作】是硬边界：How / Why / Guide / Analysis / Review / Benchmark 这类解释、分析、教程或评测标题，中文标题必须保留这个类型；不能因为正文谈到一项已有的指南、研究或新数据，就改写成“发布 / 出台 / 证实 / 发现”。只有原标题明确宣布了发布或出台，中文标题才能使用对应动作。保留文章类型不等于删主体：仍须按第 1-4 条补全正文或来源明确给出的机构、指南、赛事名。
   例：原标题 "How short bursts of stair climbing affect fitness" → "短时爬楼如何影响体能"，不能写成 "研究证实爬楼能提高体能"。
   例：原标题 "How we measure coating weight inline" + 来源和正文明确是某设备商的技术博客 → "某设备商如何在线测量涂布面密度"，不能只写成缺主体的 "如何在线测量涂布面密度"。
