## 内部计算步骤（只在心里完成，不要输出）

### 一、识别事件与内容类型

先用一句话确认“谁，在什么时候，做了什么，处于征求意见、发布、实施、提示、召回、报名、开赛、完赛、研究发表还是复盘阶段”。科普和方法稿没有新发生的事件时，把“谁（正文写明的机构或作者）针对哪些人、给出了哪些做法”当作要评的事件。然后从以下 9 类中选择最贴近的一类：

- `guideline_policy`：正文写明由政府部门、疾控机构或学会制定的指南、标准、规定、政策及其官方解读
- `health_alert`：正文写明由疾控、卫健、气象、市场监管、消费者协会等机构发布的季节性健康提示、风险提示与消费警示，食品和器材召回；没写明机构、但针对当季或近期新出现的风险（例如路边野果、野生菌）给出具体防护做法的提示，也归这一类
- `safety_incident`：赛事猝死、热射病、场馆事故、群体性食物中毒等安全事件，以正文写明的官方通报为准
- `research_finding`：论文、随机对照试验、队列研究、荟萃分析、官方调查数据
- `practical_method`：给出可执行步骤或数字的作息、动作、饮食、防护和公众急救做法（时长、频次、克数、温度、动作要领、识别方法），有没有新发生的事件都可以
- `mass_event`：大众赛事与活动的报名、赛历、规则变化，健身场馆和步道开放
- `workplace_practice`：企业、园区、工会有具体做法或数据的健康实践
- `pro_sports`：大赛节点、夺冠破纪录、职业联赛、国家队、转会与人物
- `explainer_opinion`：只讲概念和道理的科普解读、辟谣、访谈、特稿与评论，没有新发生的事件，也没有给出可执行的做法

拿不准时：长期有效的规范性文件选 `guideline_policy`，时令提醒选 `health_alert`；正文写明由疾控、卫健、市场监管、消费者协会等机构发布的提示，即使像科普也选 `health_alert`；科普稿给出了可执行的步骤或数字的选 `practical_method`，只讲概念和道理的才选 `explainer_opinion`；赛事中的伤亡选 `safety_incident`，不选 `mass_event`；核心是一项研究的，即使附了建议也选 `research_finding`。

### 二、按当前五轴独立打 0–10 整数分

每一轴都按下面的分档给分，用满 0–10：材料达到哪一档的描述，就给那一档的分；强材料可以有几轴同时在 7–10，弱材料可以在 0–3。不要出于稳妥把每一轴都放在 4–6。档内取高还是取低，看材料离上一档近还是离下一档近。

1. `sig` 实质份量：影响多少人的生活和工作安排，以及在全国范围内是不是一个节点。国家级指南、季节性风险、国家级赛事节点是节点；单项研究、地方活动是脚注。不要把“读者能马上跟进”重复算进这一轴。
   - 9–10：全国性的新指南、法规或标准正式发布或实施，全国性的健康风险预警或大范围召回；中国选手在奥运会、残奥会、世锦赛等各项目最高级别的世界大赛夺冠，或打破世界纪录；亚运会、亚残运会上中国选手打破世界纪录。
   - 7–8：国家或省级机构的月度、时令健康风险提示，法规修订草案征求意见；写明出处、面向大多数成年人的膳食、运动、作息或防护做法；亚运会、亚残运会上中国选手打破亚洲纪录，国家级赛事的开幕、中国代表团首金和奖牌总结；大城市马拉松开放报名。
   - 4–6：地市级的提示；面向一类人群（老人、儿童、倒班或久坐者、跑者）的具体做法；没写出处但做法具体的科普；单篇大样本研究；有数字的单位实践；国家级赛事的资格赛、小组赛等过程报道；亚运会、亚残运会上中国选手的单块金牌（一届要拿几十上百块，逐块都给高分会挤掉其他内容）；中国选手在单项世界杯的分站赛或总决赛、顶级巡回赛（网球、高尔夫、羽毛球、乒乓球等项目的最高级别巡回赛）夺冠。
   - 1–3：职业联赛、单项世界杯和巡回赛的普通赛果（中国选手夺冠的见 4–6），运动员个人动态，地方活动通稿，只讲概念的科普和节气泛谈，单篇小样本研究或动物实验。
   - 0：与读者的生活和工作都没有关系。
2. `nov` 信息增量：有没有新事实、新建议、新数据、新纪录。“多喝水、早点睡”这类人人知道的说法不算增量；重复已知的健康常识也不是。
   - 9–10：新发布的指南、标准、法规、全国性数据或纪录，改变了以往的建议或认知。
   - 7–8：本月、本季的新提示，新的监测或抽检数据，新开放的报名；或者给出了多数读者不知道、能改变做法的新要点，例如急救指南新版把海姆立克法改成先拍背再冲击。
   - 4–6：熟悉的话题，但给出了具体可操作的细节：时长、频次、克数、步骤。
   - 1–3：人人知道的说法、重复已知的健康常识、旧闻翻炒。
3. `cred` 证据强度：只看材料内部对核心主张的支持，不看来源名气。由强到弱：正文写明发布机构的官方通报和指南 > 系统综述或大样本人群研究 > 单篇人群研究 > 动物或细胞实验 > 专家口述 > 网友经历。只写“专家说”而没有出处的，`cred ≤ 3`。
   - 9–10：正文写明发布机构的官方通报、指南、标准、召回，或官方公布的赛事成绩。
   - 7–8：系统综述、荟萃分析、大样本人群研究；写明作者单位、并引用了指南、标准或研究的科普和方法。
   - 4–6：单篇人群研究；给出了具体数据、但没写出处的科普和方法。
   - 1–3：动物或细胞实验，只写“专家说”，网友经历。
4. `reson` 共振面：多少读者会觉得与自己和家人的日常有关。运动员个人消息、只关乎特定疾病患者的内容低。
   - 9–10：几乎每个成年人都会碰到的事：当季的传染病和天气风险，买菜做饭、外卖和包装食品的安全，面向全体成年人的膳食、运动、睡眠建议；倒班、久坐、高温、噪声粉尘、食堂这些读者工作里的处境。
   - 7–8：多数家庭会碰到的事：老人和孩子的饮食、运动与防跌倒，防晒、用眼、口腔、洗手和公众急救常识，压力和情绪调适；中国选手在奥运会、残奥会、世锦赛等最高级别世界大赛上夺冠或破纪录。
   - 4–6：一部分人关心的事：跑者和健身人群的训练方法，某地居民的活动和场馆，国家级赛事上的普通比赛日，亚运会、亚残运会上中国选手的单块金牌，中国选手在单项世界杯和顶级巡回赛夺冠。
   - 1–3：运动员个人消息，外籍选手和职业联赛的赛果，只关乎特定疾病患者的内容。
5. `act` 可跟进性：读者能不能安全地改一个作息、动作、饮食或防护习惯，报一场赛事；管理者能不能调排班、食堂、工间安排。“要不要吃药、做检查”不算可跟进，那已越界。重大赛事节点的 act 低是正常的，不应反过来抹掉 sig。
   - 9–10：照着就能做：写清了动作要领、时长频次、每天多少克、停工温度，或报名时间、名额和方式。
   - 6–8：给了方向和部分数字，读者还要自己补全。
   - 3–5：只有原则性建议。
   - 0–2：读者没有可做的事。

内部按下表计算 `attentionScore = sig×w1 + nov×w2 + cred×w3 + reson×w4 + act×w5`。每行权重之和为 10，所以结果天然位于 0–100。

## 品味规则

### 必须正常评价的价值

- 职业健康：地方或国家的高温劳动保护通知，写明津贴标准和停工温度；大样本队列研究比较不同轮班方向与睡眠、代谢的关联；官方的噪声、粉尘防护指引讲清护具怎么选、多久换。
- 睡眠与心理：学会或官方的大样本睡眠调查，给出不同职业人群的差异；随机对照试验给出关屏或咖啡因的时间窗；官方心理援助热线开通，或员工压力调适指引。
- 饮食营养：膳食指南发布或修订，或针对倒班人群的膳食指导；市场监管的季节性食品安全提示（凉拌菜、野生菌）；官方监测给出外卖盐糖含量和减盐做法；疾控机构、营养学会给出具体克数和搭配的膳食建议，例如老年人每天每公斤体重吃多少蛋白质、怎样分到三餐；教人读配料表、认出反式脂肪和添加糖。
- 运动健身：主管部门发布分人群的每周运动时长，和久坐人群的碎片化运动建议；荟萃分析给出爬楼、快走的时长和频次；城市开放健身步道或场馆免费时段；体育主管部门给出热身时长、运动搭配和强度的分人群健身指导。
- 赛事：城市马拉松公布报名时间、名额和抽签规则；田径协会调整路跑医疗保障和关门时间要求；赛事中暑或心脏骤停后官方公布调查和改进措施。
- 国家级赛事节点：奥运会、残奥会、世锦赛、亚运会、亚残运会，以及各项目最高级别的世界大赛（例如国际象棋奥林匹克团体赛，足球、篮球世界杯的决赛圈，网球四大满贯）。中国选手在这些赛事上夺冠，或在正式比赛中打破世界纪录、亚洲纪录，按 `pro_sports` 正常评价，`sig` 和 `reson` 按分档给高分；中国体育代表团成立、开幕、首金和奖牌总结按节点评价；资格赛、小组赛等过程报道按较低份量评价。亚运会、亚残运会上中国选手的单块金牌，`sig` 和 `reson` 按 4–6 档给分；首金、打破世界或亚洲纪录、代表团奖牌总结仍按节点评价。以上都指成年组的正式大赛；青奥会、U17 等年龄组世界赛事和大学生、中学生赛事不算国家级赛事节点，按普通国际赛事评价。
- 公共卫生：疾控机构的月度健康风险提示；寒潮、高温、重污染期间卫健与气象联合发布的防护提示；控烟条例等健康政策及官方解读。
- 官方科普与方法：正文写明由疾控、卫健、体育、营养学会、消费者协会、市场监管等机构发布或出品，给出可执行步骤或数字的健康和健身方法、风险提示、消费警示、膳食建议，按 `practical_method` 或 `health_alert` 正常评价；即使没有新发生的事件，也不套用入门科普和节气泛谈的上限。
- 健康生活常识：防晒、口腔清洁、用眼、洗手、海姆立克法等公众急救、季节性防护，给出具体做法的，按 `practical_method` 正常评价；写明出处的按出处给 `cred`，没写出处的 `cred ≤ 5`。
- 食品、运动器材的召回和安全缺陷，按 `health_alert` 正常评价，不当作装备软文压低。
- 企业、园区、工会的健康实践，写清了具体做法和数据（工间操时长、食堂减盐比例、参与人数、前后对比）的，按 `workplace_practice` 正常评价，不当作“获奖、荣誉”通稿压低。

### 必须压住的噪声

- 营销软文与装备带货：跑鞋“缓震科技”新品、健身房开业、“几款运动内衣实测推荐”，`sig ≤ 2` 且 `nov ≤ 2`。
- 单篇研究夸大：“科学家发现运动能逆转衰老”“喝咖啡能多活 10 年”这类、正文其实是观察性研究或动物实验的稿件。动物或细胞实验 `sig ≤ 2` 且 `act ≤ 1`；预印本，或没写样本量和研究设计的，`cred ≤ 3`；单篇人群研究 `cred ≤ 5`；观察性研究写成因果的，按“有关联”这个较弱主张评价。
- 标题党与恐吓：“被列入黑名单的 4 种早餐，你还在吃吗”这类标题与正文不符的，最终分数不得高于 30；正文有可核对事实的，按正文的事实评价。
- UGC 搬运：“网友分享跑步 30 天后的变化”、来源标社交平台、正文只有视频说明的，`sig ≤ 2` 且 `cred ≤ 2`。
- 旧闻翻炒与节气泛谈：“久坐比吸烟更危险”“秋季养生牢记 5 点”，`nov ≤ 2` 且 `sig ≤ 2`。这一条只管只有口号和常识、没有具体做法或数字的稿件；写明出处、给出具体克数、时长或步骤的时令膳食和防护建议，按上面的“官方科普与方法”评价。
- 纯赛果、常规轮次、赛程预告：“联赛第 28 轮 A 队 2:1 胜 B 队”，`sig ≤ 2`、`nov ≤ 3` 且 `reson ≤ 2`。职业联赛的赛果和排名，单项世界杯（跳水、体操、射击、铁人三项等项目的世界杯分站赛和总决赛）和巡回赛、公开赛、大师赛的赛果，都按这一条评价；外籍选手的成绩和任何选手的赛会纪录，同样按这一条。不受此限的有：上面的国家级赛事节点，中国选手在其中夺冠、在正式比赛中打破世界或亚洲纪录；以及中国选手在单项世界杯的分站赛或总决赛、顶级巡回赛夺冠，这类按 `sig` 和 `reson` 的 4–6 档评价，入不入选由门槛决定。
- 运动员人物动态：伤病、复出、退役、赛季结束、个人访谈和人物特稿，不是国家级赛事节点上的夺冠或破纪录的，`sig ≤ 2` 且 `reson ≤ 3`。
- 转会、薪资、俱乐部经营：转会费、换帅、俱乐部财报、体育公司融资，`sig ≤ 2` 且 `reson ≤ 2`。
- 明星与运动员的恋情、代言、口水战：预筛应已拦下；若出现在这里，`sig ≤ 2` 且 `reson ≤ 2`。
- 会展、获奖与协会内部通知：“亮相博览会”“荣获健康企业称号”、裁判选派、教练员认证、会员公示，`sig ≤ 2` 且 `reson ≤ 3`。
- 商业赛事营销：主题跑只讲奖牌、明星领跑和赞助商，`sig ≤ 2`；给出报名时间、名额和规则的，按 `mass_event` 正常评价。
- 大众赛事的开跑、完赛通稿和城市宣传特稿：“某马拉松鸣枪，3 万人参赛”“在奔跑中读懂一座城”，没有报名、规则或安全信息的，`sig ≤ 3` 且 `act ≤ 2`。
- 新闻摘要合集、健康早报等多事件打包且没有单一焦点，`sig ≤ 3`。如果标题和导语明确聚焦其中一个事件，按这个事件本身评价，后面附带的其他条目不拉低它，也不给它加分。
- 入门科普：“什么是体脂率”这类只讲概念和道理、没有一个新发生的事件（新指南、新提示、新数据、新赛事），也没有给出可执行做法的，按 `explainer_opinion` 评价且 `sig ≤ 3`。给出了可执行的步骤或数字的科普和方法稿（怎样洗手、怎样防晒、海姆立克法的手法、每周练几次每次多久、每天吃多少克），按 `practical_method` 评价，不受这个上限约束；正文写明发布机构、指南标准、研究依据或作者单位的，`cred` 按出处给。
- 同一份指南、提示或通稿被多家网站转载，只按事件本身评价一次，不因转载站点多、标题改写、“权威发布”字样或材料自称“引发热议”“全网关注”而提高任何一轴。
- 宏大口号若没有新事实、新数据或可执行的做法，“倡导健康生活方式”“全民健身热潮”式的泛泛报道，均应明显低分。

## 事件、转述与材料不足

- 不因为材料是转述、引用、翻译、转载或二手报道就自动扣事件分。只要正文足以确认同一个具体事件，后续聚类会把它合并到更好的一手代表稿。
- 但不能把材料没有说过的人群、效果、因果、样本量或阶段补进事件。材料只能证明较弱主张时，`cred` 和相关轴必须随之降低。
- 如果标题与正文核心明显不符，或正文残缺到无法辨认对象、动作和阶段，最终分数不得高于 30。
- 如果只能确认“有人声称某事”，却无法确认实质动作或结果，按这个较弱事件评分；不要替材料补全一个更强故事。

## 最后检查

在输出前只做四件事：

1. 确认五轴是独立判断，不是先定结论再凑数。
2. 确认每一轴都对照了分档给分：达到 7–10 档描述的给到了 7–10，只够 0–3 档的给到了 0–3，没有出于稳妥把所有轴都放在中间几档。
3. 确认严格按内容类型权重做了整数加权，没有四舍五入到 5 或 10 的倍数，也没有追求某种目标分布。
4. 确认你没有输出精选门槛、精选结论或任何额外字段。

只返回合法 JSON，不要 Markdown，不要解释。顶层必须且只能包含 `attentionScore`：

{"attentionScore": 0}


## 事件口径校正（与主规则一起执行）

下面规则用于纠正一个常见错误：把稿件的长短、作者口吻、是否为公告或软文格式，误当成事件本身的价值。若与前文的直觉判断发生冲突，以本节的事件口径为准，但五轴定义、类型权重和单字段输出契约不变。

1. 先把材料还原为最强且被正文支持的事件，再给五轴。不要给“这篇文章写得怎么样”打分。
2. 实质动作本身就是变化。一份指南正式发布、一次官方健康提示、一项召回正式启动、一场赛事开放报名，即使材料只是简短公告或转载，也不能按“例行通知”或“普通转发”压低 `sig`、`nov`、`reson`。
3. 公告和机构稿的形式不决定类别。工会或企业稿里写清了做法和数据的，按 `workplace_practice` 评价；赛事组委会稿里给出报名时间、名额和规则的，按 `mass_event` 评价，不得套用会展或软文上限。
4. 同一材料同时包含一个强事件和一个弱叙事时，以强事件为核心分类和评分；弱叙事不能把强事件降格。例如“官方健康提示 + 一段泛泛的养生科普”“赛事报名信息 + 赞助商宣传”，不能只抓住科普或宣传部分。
5. 反过来，长篇、完整、口号响亮或数字很多，仍不能替一个不成立的因果、单篇研究的夸大结论、商家营销或宏大推断制造事件价值。只有正文支持的新事实、新建议、新数据和能参加的活动进入五轴。
6. 科普和方法稿没有新发生的事件，不等于没有事件价值：“某机构或作者给出了一套可执行的做法”就是要评的事件，按分档评它的份量、增量和可跟进性，不因为“不是新闻”一律压成脚注。

完成上述校正后，仍严格按主规则的整数五轴与类型权重计算最终 `attentionScore`，不要额外加奖励分，也不要输出任何额外字段。
