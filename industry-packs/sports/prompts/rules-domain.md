【健康与运动翻译规则 — 本平台内容来自健康生活、职业健康、饮食营养和大众运动，严格遵守】

1. 研究术语按固定译法：
   - Association / Associated with = 关联 / 与……有关联（不译“导致”“引起”）
   - Cohort study = 队列研究；Cross-sectional study = 横断面研究；Observational study = 观察性研究
   - Randomized controlled trial / RCT = 随机对照试验；Meta-analysis = 荟萃分析；Systematic review = 系统综述
   - Preprint = 预印本（写明“尚未经同行评议”）；Peer-reviewed = 经同行评议
   - In mice / In rats = 在小鼠 / 大鼠实验中；In vitro = 体外实验（细胞实验）
   - Risk / Relative risk / Absolute risk = 风险 / 相对风险 / 绝对风险，数字照原文，不把相对风险写成绝对风险
   - Guideline = 指南；Recommendation = 建议；Advisory = 提示

2. 健康生活与职业健康用语：
   - Shift work = 倒班；Night shift = 夜班；Sedentary = 久坐；Prolonged standing = 久站
   - Heat stress = 热应激；Heat illness = 中暑；Heatstroke = 热射病；PPE = 个人防护用品
   - Physical activity = 身体活动；Moderate-to-vigorous = 中高强度；Steps = 步数
   - Sleep hygiene = 睡眠卫生；Stress management = 压力管理（不写成诊断或治疗）
   - Ultra-processed food = 超加工食品；Sodium = 钠（盐的换算照原文，不自己换算）

3. 赛事与运动用语：
   - Marathon / Half marathon = 马拉松 / 半程马拉松；Cut-off time = 关门时间；Ballot / Lottery = 抽签
   - Registration = 报名；Bib = 号码布；Aid station = 补给站
   - World Championships = 世锦赛；Olympic Games = 奥运会；Personal best = 个人最好成绩；World record = 世界纪录

4. 以下缩写和单位一律保留原文，不翻译不加中文括注：BMI、kcal、kJ、km、bpm、VO2max、WBGT、AQI、PM2.5、dB；机构缩写 WHO 写世界卫生组织，China CDC 写中国疾控中心，美国的 CDC 写美国疾控中心，FIFA、IOC、World Athletics 保留英文或用通用中文名（国际足联、国际奥委会、世界田联）。拿不准有没有通用中文名时保留英文原文，不要自己音译。

5. 数字 / 单位 / 标准编号 / URL 一字不改保留：
   - 指南和标准的名称、编号原样保留，不要“翻译性扩写”
   - 时长、频次、温度、名额、比例不换算、不四舍五入：每周 150 分钟不要写成“两个多小时”，40℃ 原样保留，2 万个名额不要写成“数万”
   - 区间和比例保留原文的阿拉伯数字
