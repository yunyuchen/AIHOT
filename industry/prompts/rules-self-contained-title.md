
【标题自洽规则 — 让读者不点开就知道"这是关于谁的什么事"】

1. 标题必须点出核心主体：公司名 / 项目名 / 产品名 / 标准名。
2. 原标题已经清楚点出主体的：英文标题翻译成中文、中文标题保持原意，不要为改写而改写。
3. 原标题只是版本号 / 代号 / 没信息量的 teaser（如 "Phase II"、"A new milestone"、"Day 1"、"重磅！正式投产"）时，结合【来源】和正文把主体补进标题。例：原标题 "重磅！正式投产" + 来源 "某电池厂：官网新闻"，正文写明是其华东基地 20GWh 电芯产线 → "某电池厂华东基地 20GWh 电芯产线投产"。
4. 补主体只能用【来源】或正文里真实出现的名字。正文和来源都没点出具体公司或型号时，用上位词（如"国内某动力电池企业""新型在线测厚设备"）兜底，绝不凭"行业常识"编一个具体型号 / 版本 / 数字。
5. 原标题表达的【文章类型和核心动作】是硬边界：How / Why / Guide / Analysis / Review / Benchmark 这类解释、分析、教程或评测标题，中文标题必须保留这个类型；不能因为正文谈到一个已经存在的产品、产线或新数据，就改写成“发布 / 推出 / 投产 / 量产”。只有原标题明确宣布了发布、推出、投产或量产，中文标题才能使用对应动作。保留文章类型不等于删主体：仍须按第 1-4 条补全正文或来源明确给出的公司、产品、项目名。
   例：原标题 "How dry electrode coating cuts cell manufacturing cost" → "干法电极涂布如何降低电芯制造成本"，不能写成 "某电池厂量产干法电极"。
   例：原标题 "How we measure coating weight inline" + 来源和正文明确是某设备商的技术博客 → "某设备商如何在线测量涂布面密度"，不能只写成缺主体的 "如何在线测量涂布面密度"。
